# 매출 누수 진단 리포트 — Track 2 Mission

> 대시보드는 보통 **번 돈**을 보여줍니다. 이 리포트는 **새는 돈**을 봅니다.

분양 CRM 합성 데이터 5개 표(4,003행)를 정리하고, 놓친 고객·방치된 상담·추적 불가 리드·
저효율 광고 예산을 전부 **금액으로 환산**해 우선순위를 매긴 뒤, **내일 전화할 고객 30명**까지
뽑아내는 단일 페이지 리포트입니다.

**공개 링크:** _(배포 후 여기에 URL 기입)_

## 이 팀의 차별점

| | 일반적인 접근 | 이 리포트 |
|---|---|---|
| 관점 | 실현 매출·건수 KPI 나열 | 실현 매출과 **누수 6종**을 같은 축에 세워 비교 |
| 데이터 품질 | 정리했다고 언급 | 처리 로그 **20+ 규칙**을 검색 가능한 표로 공개, before/after 예시 포함 |
| 교차 검증 | 표별로 따로 집계 | **표 간 정합성 검증** — 가격 스케일·FK·기간 불일치를 수치로 적발 |
| 결론 | "이렇게 하면 좋겠다" | **점수화된 액션 큐 TOP 30** (고객·추천 매물·추천 멘트까지) |
| 도구 | 차트 라이브러리 | 외부 차트 의존성 0 — SVG 직접 렌더링 |

### 가장 위험했던 발견

`units.csv`의 분양가와 `contracts_raw.csv`의 실계약금액은 **상관계수 -0.059** — 아무 관계가 없습니다.
마스터 표시가는 평당 9,298만원(전국 최고가 아파트를 넘는 수치), 실계약가는 평당 986만원.
**두 표를 그대로 합산하면 매출이 9.4배 부풀려집니다.**
이 리포트는 매출·재고를 실계약가 기준으로만 산출하고, 마스터 표시가는 `price_listed`로 분리 보관합니다.

## 핵심 수치

- 계약 완료 매출 **550.8억** / 식별된 누수 **727.3억** (잠재 매출의 56.9%)
- 최대 누수: 계약희망 후 미전환 271명 → **290.9억**
- 미계약 재고 96세대 **243.7억** · 추적 불가 리드 154건 **73.5억**
- 액션 큐 TOP 30 기대 계약금액 **32.0억**

## 구조

```
pipeline/clean.py      정리 파이프라인 (표준 라이브러리만, 외부 의존성 0)
pipeline/schema.sql    Supabase 스키마 — 정리 규칙을 CHECK·FK·UNIQUE 제약으로 승격
pipeline/seed.sql      정리 완료 데이터 시드 (clean.py가 생성)
data/raw/              원본 CSV 5종
data/clean/            정규화된 CSV 5종
docs/CLEANING_LOG.md   처리 로그 (clean.py가 생성)
public/                배포되는 정적 사이트
```

## 재현

```bash
python pipeline/clean.py          # 정리 + dataset.json + seed.sql + 처리 로그 생성
python -m http.server 8000 -d public
```

Supabase: SQL Editor에서 `pipeline/schema.sql` → `pipeline/seed.sql` 순서로 실행.

## 정리 원칙

1. **삭제보다 플래그** — 이상치·결측은 지우지 않고 사유를 별도 컬럼에 남김
2. **결측을 0으로 채우지 않음** — 대출금 0원은 '현금 완납'과 구분 불가
3. **추정에는 신뢰도 표기** — 유입경로 '광고' → '옥외광고' 매핑은 `lead_source_conf='추정'`
4. **재발 방지까지** — 표준화 규칙을 DB 제약으로 승격

## 한계

- 기대매출은 실측 전환율(42.6%)을 적용한 **추정치**이며 확정 매출이 아님
- 광고비는 2025-12까지, 상담·계약은 2026년까지 → 채널 ROI는 겹치는 구간만 산출
- 광고 리드 137,068건과 고객 600명은 1:1 대응하지 않아 퍼널은 '고객 등록' 이후만 사용
- **모든 데이터는 합성(가상) 데이터**이며 실제 고객·계약·건물과 무관
